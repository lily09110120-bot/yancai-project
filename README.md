# 🎨 非遗岩彩数字传承系统 (Yancai Digital Museum)

> 数字化呈现矿物颜料之美，探寻丝绸之路上的色彩基因。

## ✨ 项目亮点
- **沉浸式时间轴**：通过动态背景切换演示岩彩的历史变迁。
- **响应式设计**：完美适配 PC、平板与移动端。
- **工程化实践**：基于 Vue3 + Vite + Tailwind CSS 构建，严格遵循 Git 规范。

## 🛠️ 技术栈
- 框架：Vue 3 (Composition API)
- 样式：Tailwind CSS
- 部署：Vercel
